# Iqa' Bambi 8/4

**Bambi** (Bambī) — 8/4, 16 eighths per measure.

## Overview

> Iqa‘ Bambi (also called Bamb) is a stretched-out Egyptian 8/4 iqa‘ that beautifully accompanies improvisations and sparse vocal sections. It is customary to start playing Bambi from the 7th beat (the dum before last), thereby emphasizing the 3 consecutive dum-s that start each cycle. An alternate form of Bambi actually starts the measure with the 3 consecutive dum-s.
>
> — [MaqamWorld](https://www.maqamworld.com/en/iqaa/bambi.php)

---

## Pattern

**Notation:** `D - - T - - T - - T - - D - D -`  
**Base unit:** eighth | **Total divisions:** 64 (per measure)

**Legend:** `D` = Dum (bass, accent 2) | `T` = Tak (sharp, accent 1) | `k` = Ka (ghost note, no accent) | `-` = Rest

**Events (position, duration, accent):**

```
D(0,8,2) -(8,4,0) T(12,8,1) -(20,4,0) T(24,8,1) -(32,4,0) T(36,8,1) -(44,4,0) D(48,8,1) D(56,8,1)
```

## Tempo

- **Typical:** 115 BPM
- **Range:** 90–140 BPM

## Feel

Lilting, egyptian folk.

## Usage

- **Genres:** folk, shaabi
- **Regions:** Egypt

## MIDI

- **Dum (D):** note 36 (C2)
- **Tak (T):** note 50 (D3)
- **Ka (k):** note 39 (D#2)

## Project note

8/4, one measure per cycle. Pattern confirmed by the project owner (2026-10-20): quarter D, eighth rest, quarter T, eighth rest, quarter T, eighth rest, quarter T, eighth rest, quarter D, quarter D. The two closing dums plus the next cycle's opening dum give the three consecutive dums MaqamWorld describes.
